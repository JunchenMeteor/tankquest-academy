# 坦克行走机构修复设计

## 目的

当前高画质 GLB 和中低画质程序化模型都存在明确的轮轨几何错误。目标是在不引入物理引擎的前提下，让两套模型的行走装置结构合理、轮轨接触一致、轮子和履带能随敌我车辆行驶。

## 已确认的问题

- GLB 前诱导轮超出同高度履带前端约 30.54 源单位；最后一对负重轮与主动轮重叠 6.10。
- GLB 所有轮子共用同一网格，没有主动轮齿形、可辨识托带轮或悬挂结构。
- 程序化模型的负重轮底与下段履带内侧相差 0.3307，端轮重叠 0.43–0.50，履带节长度是节距的 5–6 倍。
- 程序化模型的前后功能轮与 +X 车头及 GLB 约定相反。
- 只有玩家轮组更新；敌方移动时轮组静止。GLB 滚动半径由硬编码值近似，程序化履带节不运动。

## 决定

- 以通用履带坦克结构为准，不复原某个历史型号。
- GLB 使用明确的分轮缩放和位置修正，使各轮与履带下支内表面接触；直线段负重轮基本共线，诱导轮随前端弧形履带独立抬升。诱导轮、负重轮、主动轮之间不得重叠，端轮不得穿出履带轮廓。
- 为主动轮添加随轮旋转的齿形，在上下履带之间添加简化的托带轮和悬挂视觉结构；这些部件必须归属车体或对应轮节点。
- 滚动半径从归一化后的实际几何取得，不再统一使用 0.38 近似值。
- 程序化模型根据履带直线段可用空间安排 2–3 对负重轮，不硬塞 5 对；前后为主动轮在后、诱导轮在前。
- 程序化履带整体上移，使负重轮接触下段、托带轮接触上段；履带节按实际周长确定数量并保留间隙。
- 履带节沿闭合路径移动，GLB 继续使用贴图滚动；敌我车辆都按实际位移驱动轮轨。真实悬挂物理、履带刚体碰撞和差速转向物理不在本次范围。
- 保留现有模型关节、PBR 贴图、炮塔/炮管行为和战斗数值。

## 验收

- 新增几何回归：左右对称、轮底同线、相邻轮无负间隙、端轮不越界、前后功能轮正确、履带节节距不小于节长。
- Blender 数值审计和去裙板侧视确认无已知穿模；星盾、铁山与程序化模型均检查。
- 玩家与敌方前进、后退、原地静止时轮轨行为正确，轮子轴心不漂移。
- 全仓质量门禁、CI、双环境同镜像部署及两轮 Playwright 对抗性复验通过。
