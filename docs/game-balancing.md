# 游戏数值与经济系统

## 1. 核心原则

- 学习表现影响奖励。
- 坦克升级改善手感，但不能替代学习。
- 儿童模式不做强付费刺激。
- 数值简单可解释。

## 2. 坦克属性

坦克初始属性为 1-5，升级后的有效属性上限为 10。七项属性均可升级：

```text
火力：炮弹伤害、穿深、弹速和装填
机动：前进/倒退速度、加速度和车体转向
装甲：车体生命、方向装甲、减伤和重量
隐蔽：被敌人发现的可见度
视野：发现敌人的距离
精度：炮弹散布和炮管俯仰速度
炮塔转速：炮塔水平旋转速度
```

每项属性独立记录 0-5 级购买进度，初始属性不再决定能否继续升级。例如铁山初始装甲为 5，仍可通过五次装甲升级达到有效值 10。每升一级必须有可感知变化，后端的拥有坦克列表同时返回有效属性和各项购买等级，下一局使用有效属性。

## 3. 奖励类型

```text
星星：通关评价和解锁
零件：升级属性
徽章：学习成就
训练点：通用软货币
```

## 4. 星级规则示例

```text
1 星：完成主要目标
2 星：答题正确率 >= 60%
3 星：答题正确率 >= 80% 且坦克未被击毁
```

## 5. 升级规则

任务奖励的零件为通用升级零件；库存键 `cannon` 为兼容既有玩家数据而保留，不再表示只能升级炮管。后端按当前购买等级原子扣费，费用依次为：

```text
Lv0 -> Lv1: 2 个通用零件
Lv1 -> Lv2: 4 个通用零件
Lv2 -> Lv3: 6 个通用零件
Lv3 -> Lv4: 8 个通用零件
Lv4 -> Lv5: 10 个通用零件
```

单项升满共需 30 个零件。结算页可选择任一属性，并在购买前显示真实的升级前后战斗数值；购买后再次显示结果和剩余零件。既有升级等级原样保留，不清空、不重复补偿。

## 6. 难度调整

正式数学内容从乘除法开始，不再以 20 内加减法作为入门：

```text
难度 1：乘法口诀和对应的整除除法
难度 2：两位数乘一位数、两位数及以上除以一位数
难度 3：更大数乘一位数、三位数除以一位数（整除）
难度 4：含乘除的两步和三步混合运算
```

每档 10 个中英双语题目变体，数学题提供 4 个唯一选项。乘法和除法技能键在各难度保持连续，使后端自适应推荐可以沿已发布关卡逐级提升；历史加减法学习记录仍保留，但不影响新题发布。题目 ID 不变，既有对局和答题记录继续有效。

连续失败：

- 减少敌人。
- 增加提示。
- 降低题目干扰项。

连续成功：

- 增加题目难度。
- 增加敌人组合。
- 提高奖励上限。

## 7. 防数值失控

- 每日奖励可设软上限。
- 坦克属性有等级上限。
- 关卡有推荐战力但不能强卡。
- 成人模式和儿童模式奖励可分池。
